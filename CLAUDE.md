## Project

Arcade Vault — a platform for playing games online and competing for the highest score (see README.md, in Spanish). The codebase is currently the unmodified Next.js scaffold (App Router) — no game/leaderboard features exist yet.

## Commands

- `npm run dev` — start the dev server (also regenerates the AGENTS.md breaking-changes block via `node_modules/next/dist/server/lib/generate-agent-files.js`)
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — ESLint (flat config in `eslint.config.mjs`, extends `eslint-config-next` core-web-vitals + typescript)

There is no test runner configured yet.

## Skills

Usa siempre /frontend-design para diseñar interfaces de usuario

## Architecture

- Next.js 16 App Router, TypeScript, React 19, Tailwind CSS v4 (via `@tailwindcss/postcss`).
- `app/layout.tsx` / `app/page.tsx` — root layout and home page (default scaffold content).
- Path alias `@/*` maps to the repo root (see `tsconfig.json`).
- This project intends to follow Spec Driven Design (`/spec` and `/spec-impl`), using skills from `Klerith/fernando-skills` (installed via `npx skills@latest add Klerith/fernando-skills`). No spec files exist in the repo yet.

## Working in this repo

Since this is a newer/unfamiliar Next.js version, consult `node_modules/next/dist/docs/` (per AGENTS.md) before relying on prior Next.js knowledge — APIs and conventions may have changed. Do not remove the AGENTS.md breaking-changes block; it is regenerated by `next dev` and should be committed as-is.
